# Card Arena

AI를 상대로 즐기는 웹 카드게임 두 종. 첫 화면에서 **텍사스 홀덤**과 **섰다** 중 고릅니다.
두 게임 모두 매 판 딜러가 돌아가고, 셔플 방식은 매 판 네 가지 중 무작위로 뽑힙니다.

React (Vite) · Tailwind CSS v4 · Framer Motion · Lucide React

## 실행

```bash
npm install
```

```bash
npm run dev
```

빌드는 `npm run build`, 결과 확인은 `npm run preview`.

## 게임 흐름 (홀덤)

1. **설정** — AI 봇 수(1~5), 시작 칩(500/1,000/2,000/5,000), 블라인드(SB 5/10/25/50)를 고릅니다.
2. **셔플** — 딜러 버튼이 매 핸드 다음 자리로 넘어갑니다. 딜러가 사람이든 AI든 매 판
   Riffle / Overhand / Mash / Strip 중 하나가 무작위로 뽑혀 그 연출이 재생된 뒤 카드가 분배됩니다.
3. **베팅** — 프리플롭 → 플롭(3장) → 턴(1장) → 리버(1장) → 쇼다운.
   Fold / Check / Call / Raise(슬라이더 + 1/2·3/4·팟 프리셋) / All-in.
4. **쇼다운** — 살아남은 플레이어마다 7장 중 최선의 5장을 뽑아 **약한 손부터 한 줄씩 공개**합니다.
   각 줄에는 지은 5장이 그대로 펼쳐지고, 그중 자기 홀카드였던 것에는 금색 밑줄이 붙어
   "무엇으로 지었는지"가 바로 보입니다. 마지막에 공개되는 승자에게 왕관과 획득 칩이 붙습니다.
   폴드로 끝난 핸드는 공개할 것이 없으므로 간단한 배너만 뜹니다.
   칩이 떨어진 플레이어는 다음 핸드부터 탈락 처리됩니다.

## 구조

베팅 루프·사이드팟·정산은 두 게임이 완전히 같아서 `engine/`으로 빼두었습니다. 게임별 폴더에는
덱·족보·AI·진행 순서만 들어갑니다.

## 섰다 규칙

화투 20장에서 두 장. 앤티를 걷고 한 장씩 돌린 뒤 베팅, 두 번째 장을 돌린 뒤 다시 베팅합니다.

족보는 위에서부터 **38광땡 > 18광땡 > 13광땡 > 장땡~1땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 >
세륙 > 갑오 > 8끗~1끗 > 망통** 순입니다.

특수 규칙 세 가지는 설정에서 켜고 끌 수 있습니다.

| 규칙 | 효과 | 기본값 |
| --- | --- | --- |
| 암행어사 (4·7) | 13광땡·18광땡을 잡습니다. 38광땡은 못 잡습니다 | 켜짐 |
| 땡잡이 (3·7) | 장땡까지 모든 땡을 잡습니다. 광땡은 못 잡습니다 | 켜짐 |
| 구사 (4·9) | 쥐고 지면 판을 무르고, 판돈은 다음 판으로 넘어갑니다 | 꺼짐 |

앞의 두 규칙은 일부러 순환을 만듭니다. 암행어사는 18광땡을 이기고, 18광땡은 장땡을 이기고,
장땡은 암행어사를 이깁니다. 셋이 한 판에 모이면 승자가 정해지지 않으므로, 그럴 때만 특수 규칙을
무시하고 순수 족보 순위로 판을 내립니다.

### 홀덤 룰 구현 메모

- **블라인드/액션 순서** — 헤즈업에서는 딜러가 SB를 내고 프리플롭 선을 잡습니다(포스트플롭은 BB 선).
  3명 이상이면 딜러 다음이 SB, 그다음이 BB, UTG부터 액션이 시작됩니다.
- **레이즈 재개** — 최소 레이즈액 이상의 레이즈만 다른 플레이어의 액션 권한을 다시 엽니다.
  이보다 작은 올인(숏 올인)은 액션을 재개하지 않습니다.
- **사이드팟** — 각 플레이어의 총 투입액을 기준으로 레벨별 팟을 만들고, 자격자끼리 비교합니다.
  아무도 가져갈 수 없는 구간(미콜된 베팅)은 낸 사람에게 그대로 돌려줍니다.
- **AI 판단** — 프리플롭은 스타팅 핸드 점수, 플롭 이후는 몬테카를로 시뮬레이션(200회)으로
  승률을 추정한 뒤 팟 오즈와 비교합니다. 봇마다 공격성·블러프 빈도·타이트함이 다릅니다.

## 셔플 연출

| 방식 | 연출 |
| --- | --- |
| Riffle | 덱이 좌우로 갈라져 호를 그리다 번갈아 교차하며 겹칩니다 |
| Overhand | 윗부분 뭉치가 차례로 떨어져 아래로 들어갑니다 |
| Mash | 두 뭉치가 측면에서 맞물려 부드럽게 들어갑니다 |
| Strip | 얇은 뭉치를 여러 번 떼어내 앞으로 옮깁니다 |

## 사운드

효과음은 전부 Web Audio API로 실시간 합성합니다. 음원 파일이 없어 용량이 늘지 않고 오프라인에서도
그대로 동작합니다. 카드 분배·플롭/턴/리버, 칩 소리(콜/레이즈/올인), 체크 노크, 폴드, 승패 징글이
있고 셔플은 방식별로 소리가 다릅니다(리플은 촤락, 오버핸드·스트립은 뭉치 떨어지는 소리).

헤더의 **소리/음소거** 버튼으로 끌 수 있고 설정은 `localStorage`에 저장됩니다. 브라우저 자동재생
정책 때문에 오디오는 첫 클릭 시점에 활성화됩니다.
